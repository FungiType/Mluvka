# Mluvka: Contemporary geometric typeface
![Mluvka v3 banner](/readme/Mluvka_v3_banner.jpg)

A contemporary geometric typeface balancing clarity, personality, and versatility. Mluvka is designed to perform across both expressive display settings and longer reading contexts.

## 👨‍💻 About 
Mluvka is currently in version 3, bringing a refined approach to its letterforms. This update introduces subtle adjustments to proportions, contrast, and overall rhythm, resulting in improved readability and making the typeface more suitable for continuous text than previous versions.

![Mluvka v3 vs previous versions](/readme/Mluvka_v3_Design.gif)

The typeface is equipped with a rich set of OpenType features, offering both flexibility and typographic depth. These include 8 stylistic sets, along with advanced features such as ligatures, tabular figures, and case-sensitive forms. 

Together, they allow designers to tailor the typeface to a wide range of visual contexts.

![opentype features](/readme/Mluvka_v3_Opentype.gif)


## ❤️ Font pairing
Mluvka pairs particularly well with typefaces that feature a larger x-height, creating a balanced and harmonious typographic contrast.
